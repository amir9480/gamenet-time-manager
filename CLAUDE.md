# Gamenet Timer Manager (نرم افزار مدیریت زمان گیم نت)

Single-page Persian (RTL, Vazirmatn) game-net session/cost tracker. React + Vite + TypeScript + Tailwind v4 + shadcn/ui (Base UI based "base-nova" style), wrapped as a Tauri v2 desktop app. Data (price types, extra items, sessions, history) lives in IndexedDB via Dexie; only theme/accent live in `localStorage`.

## Commands (pnpm only)
- `pnpm dev` — Vite on `0.0.0.0:3000` (strictPort; Tauri `devUrl` points at `localhost:3000`).
- `pnpm build` — `tsc -b && vite build` (strict, `noUnusedLocals`); run after every change.
- `pnpm tauri dev` — desktop window. `pnpm tauri build --no-bundle` — portable exe in `src-tauri/target/release/` (named after the Tauri `productName`) (no installer; window starts maximized).
- Add shadcn components with `pnpm dlx shadcn@latest add <name> -y`.

## Product model
- **Rates** (نرخ‌ها): named rate groups, each with several per-hour prices + a default (`RateGroup`/`Price`). **Devices**: categories (default پی‌سی، پلی‌استیشن، بیلیارد، پینگ‌پنگ) → devices created in bulk (prefix + count + start number); each device links to ≥1 rate groups and offers all their prices (grouped in selects). A **session** runs on one free device: Add-session picks category (last used is remembered in localStorage `gamenet-last-category`) → free device → price (default = first group's default) → optional **customer**. The card's price select ends with «تغییر دستگاه…» (`switchDevice`: closes the segment, opens one on the new device/price; paused sessions apply it on resume). Ending (اتمام) shows a cost breakdown dialog and, once confirmed, writes history and **removes** the session. There is no free-text session name anymore.
- Settings dialog is draft-based (ذخیره/انصراف, close = cancel, discard-confirm when dirty, save disabled while a name is empty / a price is 0 / a device has no rate). Tabs: عمومی (dark mode, accent, autostart), نرخ‌ها (`RateGroupsEditor`), دستگاه‌ها (`DevicesEditor`), بوفه (`ExtraItemsEditor`: extra categories + items; the picker shows category filter chips only when >1 category). Customers are NOT in Settings: a separate `CustomersDialog` (top-bar Users button; search + 8/page, edit/delete save immediately, soft delete via `deleteCustomer`; `NewCustomerDialog` creates/edits, also inline from the session flow). `saveSettings` ignores customers. Deleting a price/device/customer used by a running session is blocked (`usageOf`); categories/rate groups must be empty/unused first.
- Cost: a session is a list of **segments** (one continuous run on one device at one price; each carries `typeId` + mirrored price name/value and `deviceId/deviceName/categoryName`). Saving Settings rewrites these mirrors for ALL live sessions via `applyPrices`/`applyDevices`/`applyExtraItems` (in one transaction, `saveSettings`); history snapshots are never touched. Changing the price while running closes the segment and opens a new one. Time cost is billed per whole second, rounded up (`segmentCost`). Extra time entries (custom name + minutes + a price from the device's groups; snapshot) are billed at that entry's rate; extra items are `price × qty` (catalog items keep `catalogId`; the «موارد دیگر» item has a raw price and optional description). Total = Σ segments + extra times + extra items.
- Wording: the extra-items catalog (`extraItems`/`extraCategories`, Settings tab, picker, stats) is called **«بوفه»** (never «موارد اضافه»/«هزینه اضافه»); extra *time* stays «زمان اضافه». Wording: a `Session` is called **«تایم»** in the UI (never «نشست», which means "sitting"): «افزودن تایم», «تایم‌های پایان‌یافته», «پایان تایم». Wording: a `DeviceCategory` is called **«نوع دستگاه»** in the UI (never «دسته‌بندی»; that word is only for extra-cost categories). New types/categories start with an empty name and a placeholder (e.g. «مثلاً پلی‌استیشن»); an empty name keeps Settings unsaveable. Devices are added with two buttons («افزودن دستگاه» single, «افزودن چند دستگاه» bulk), edited via the pencil dialog, and «نرخ همه» sets the rate groups of every device of a type.
- Display: English digits with thousands separators, label «تومان» placed **outside** inputs.

## Code map
- `src/lib/store.ts` — types, defaults (`defaultSettings`), price/device helpers (`devicePriceGroups`, `defaultPriceFor`, `freeDevices`, `selectedPrice`), session transitions (`createSession`, `pauseSession`, `resumeSession`, `changeType`, `switchDevice`), cost helpers, `buildHistoryEntry`, `useLocalStorage`. Business logic belongs here, not in components.
- `src/lib/format.ts` — `formatNumber`, `parseNumber` (accepts Persian/Arabic digits), `formatDuration`, `formatClock`. `src/lib/accents.ts` — generated accent list; `src/accents.css` — generated per-accent CSS vars (`:root[data-accent=…]` / `.dark[data-accent=…]`).
- `src/App.tsx` — reads settings/sessions via `useLiveQuery`, empty state (CTA opens Settings > دستگاه‌ها when no devices), add-session flow. `src/components/SessionCard.tsx` is the per-session UI. Dialogs: `AddSessionDialog` (step-by-step radio cards: type → device → rate → customer; steps with a single choice are skipped; busy devices stay visible but disabled with a red dot; a quick-search combobox above the steps jumps ahead), `DevicePicker` (used by `ChangeDeviceDialog`), `ChangeDeviceDialog`, `CustomerPickerDialog`/`CustomerSelect`, `ExtraTimeDialog`, `ExtraItemPicker`, `ExtraItemsManageDialog`, `SessionSummaryDialog`, `SettingsDialog`. **Every dialog with entered data must route X/Esc/overlay/cancel through `useDiscardGuard` (`DiscardDialog.tsx`).** `Timer.tsx` uses `@number-flow/react`.
- `src-tauri/` — Tauri config (`tauri.conf.json`), autostart plugin (`tauri-plugin-autostart`, permissions in `capabilities/default.json`; the JS side is guarded by `'__TAURI_INTERNALS__' in window`). App icon source: `app-icon.svg` (`pnpm tauri icon app-icon.svg`).

## Conventions & gotchas
- Style: single quotes, no semicolons, ~100 col, trailing commas. Do **not** run prettier with defaults on files (it rewrites quotes/semicolons).
- UI is RTL (`<html lang="fa" dir="rtl">`). Use logical classes (`ms-/me-/ps-/pe-/start-/end-`), not `left/right`. Keep numeric inputs `dir="ltr"`. The Switch forces `dir="ltr"`; the Dialog close button is at the top-left.
- shadcn here is Base UI: triggers use the `render` prop (e.g. `<DialogTrigger render={<Button />}>`), not `asChild`; `Select` takes `items` for label lookup. Dialog/AlertDialog content scrolls with the whole viewport (wrapper `fixed inset-0 overflow-y-auto`), never inside the dialog — don't add `max-h/overflow` to dialog contents.
- Persistence: Dexie db `gamenet-timer-manager` (`src/lib/db.ts`; tables `rateGroups`, `deviceCategories`, `devices`, `extraCategories`, `extraItems`, `customers`, `sessions`, `history`; ordered lists carry an indexed `order`). Components read via `useLiveQuery`; writes go through the helpers in db.ts. **Catalog rows are soft-deleted** (`deletedAt`, see `syncTable` in db.ts): saving Settings never removes rows, it hides them from `readSettings`; creating an entry with the same name (devices/items: same name + category) restores the old row and its id, so history/stats links stay stable. Only history rows are hard-deleted (by the user). On a schema change add a new `version(n)` with `.upgrade()` (never edit an existing one). localStorage keys (simple per-viewer settings, edited in Settings > عمومی): `gamenet-theme`, `gamenet-accent`, `gamenet-title` (app title), `gamenet-icon` (app icon: default / any Lucide icon by kebab-case name via `lucide-react/dynamic` (lazy chunks) / custom PNG data URL; see `src/lib/appIcon.ts`, `AppIcon`, `IconPicker`), `gamenet-last-category`, `gamenet-view` (`detailed`|`compact` session list; toggle on the main page; compact = 3 small cards per row via `SessionCard compact`), `gamenet-grouping` (default on; Settings > عمومی; when on and >1 device type has devices, the main page shows per-type sections plus a «همه / type» filter row).
- Ending a session (اتمام) writes a `HistoryEntry` snapshot (`buildHistoryEntry`) and deletes the session in one transaction. History UI: `HistoryDialog` (shared presets + Jalali range + customer & device-category filters above two tabs: «تاریخچه» grouped by day, 7 days/page; «آمار» = `StatsPanel` KPIs + charts). Stats math is pure in `src/lib/stats.ts`; charts use the shadcn `chart` component (Recharts) with hued `--chart-1..5` vars in `index.css`, each chart wrapped in `dir="ltr"`. Dates/clock use Persian digits via `src/lib/jalali.ts` (Intl-based, no date lib); money stays English digits.
- Timestamps drive timers (`segments[].from/to`), so running sessions survive reloads; cards re-render once per second only while running.
- TypeScript 6: don't add `baseUrl` (deprecated); the `@/*` alias is configured via `paths` and `vite.config.ts` (`import.meta.dirname`).
